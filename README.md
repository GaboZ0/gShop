# gShop

Tienda online en desarrollo para el mercado argentino.

## Tecnologías

- Next.js
- TypeScript
- Tailwind CSS

## Estado del proyecto

Actualmente incluye una interfaz inicial de tienda con:

- Catálogo de productos de prueba.
- Búsqueda y categorías.
- Carrito de compras interactivo.

## Próximos objetivos

- Integración con proveedores de dropshipping.
- Base de datos.
- Pagos online.
- Automatización de pedidos y seguimiento de envíos.

## Desarrollo local

Instalar dependencias:

npm install

Iniciar el servidor:

npm run dev

Abrir http://localhost:3000
